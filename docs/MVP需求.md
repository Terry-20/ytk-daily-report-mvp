# MVP 需求：粤通卡日报网页概念验证（unitoll.de5.net）

> 目标：验证「固定口令网页 → 上传固定材料表 → 按公式出结果表 → 下载」是否好用（含手机）。  
> **不做**原 skill 包完整 D4/D5/D7 公式；验证通过后再替换计算引擎与材料约定。  
> 部署倾向：先本机/小托管跑通闭环；算力侧倾向 GitHub Actions（边缘 Worker 不算 openpyxl），域名 `unitoll.de5.net` 之后再绑。  
> 编写：2026-10-27 Asia/Shanghai；IN 按用户【】修订同步全文。

## 1. 范围

### In
- 静态口令进入（共享弱口令，默认示例 `unitoll`；环境变量配置，勿提交仓库）
- 登录后单页：上传 **恰好 2 张** 固定文件名的 `.xlsx`
  - `材料1.xlsx`：表头含「产品数量」，值为数字
  - `材料2.xlsx`：表头含「单价」，值为数字
- 服务端做**概念验证计算**：货款 = 产品数量 × 单价；生成固定名成品 `结果.xlsx`，表头仅「货款」
- 简单选项：开始生成 / 清空本次上传 / 下载成品（若有）
- 会话与清理：
  - **网页不保留登录态**：关闭后再打开需重新输口令
  - **生成成功且网页关闭后，立即删上传**；网页未关期间可反复下载当前成品
- 中文 UI，手机 Safari 可用（逐文件选择 + 已传列表）
- MVP 验证点：材料表上传、**材料表文件名校验**、按公式出结果表、结果表下载

### Out（本 MVP 明确不做）
- 原 `build_ytk_daily_report.py` 全量公式与材料角色识别
- 历史台账 ingest / 菜单 A–F 全套
- 截图 OCR、用户账号体系、付费
- 制表日 / 港澳单牌发行数字段（正式版再加）
- Cloudflare Worker 内跑 openpyxl（边缘撑不住；正式算力走 GitHub Actions 等，本 MVP 可用本机/小容器先通）

## 2. 概念验证「简单计算」（必须可测）

1. 上传区只接受文件名精确为 `材料1.xlsx`、`材料2.xlsx`（大小写敏感按 Windows 常见习惯可忽略大小写，但扩展名必须 `.xlsx`）。缺一、多传、错名 → 中文报错，不生成。
2. 用 openpyxl 读：
   - `材料1`：定位「产品数量」列（或首行表头单元格），取第一个有效数字单元格为 `qty`
   - `材料2`：定位「单价」列，取第一个有效数字单元格为 `price`
3. 计算 `货款 = qty * price`（浮点保留合理精度，写入单元格为数字即可）。
4. 生成成品 `结果.xlsx`：单 sheet，表头仅「货款」，下一行写计算值。
5. 表头找不到、值非数字、文件损坏 → 中文报错，不生成。

> 日后把步骤 2–4 换成正式 skill 脚本、材料名与公式即可；口令页 / 上传 / 下载骨架复用。

## 3. 页面与交互

1. `/login` 或首页：口令输入 → 正确进工作台（cookie/session 或 signed token；**关浏览器即失效**）。
2. 工作台：
   - 上传区（期望恰好两文件；列表显示文件名，可删单文件）
   - 按钮：**开始生成** | **清空本次上传** | **下载成品**（无成品时禁用）
3. 生成中显示状态；失败显示中文原因（含：文件名不符、缺表、表头/数值无效）。
4. 口令错误仅提示「口令错误」。

## 4. 技术建议（实现方可调整，验收不变）

- 仓库建议私有或至少不提交真实口令 / 真实业务表。
- **MVP 优先路径**：Python 3.11+ + Flask/FastAPI（或 Streamlit）本机可跑；`openpyxl`；口令读环境变量 `MVP_PASSWORD`（默认开发可用 `unitoll`）。
- 正式上线再评估：GitHub Actions 算力 + Pages/静态入口 + `unitoll.de5.net`；**不要**把 openpyxl 塞进 CF Worker。
- 依赖锁在 `requirements.txt`。
- 附 CLI：`python scripts/mvp_calc.py --material1 材料1.xlsx --material2 材料2.xlsx --out 结果.xlsx` 方便无 UI 回归。

**验收不以「必须 Actions 网页直传」卡死**；以「口令 + 固定名上传校验 + 公式出结果 + 下载 + 关页清上传」闭环为准。

## 5. 验收标准

- [ ] 错误口令无法进入工作台；关闭页面后再开需重新输口令
- [ ] 正确口令可上传 `材料1.xlsx` + `材料2.xlsx`；错名/缺一有中文报错
- [ ] 点生成后下载到的 `结果.xlsx` 表头为「货款」，数值 = 产品数量 × 单价（与手工抽查一致）
- [ ] 清空本次后上传列表为空，旧成品不可再下（或明确提示已失效）
- [ ] 生成成功后、页面仍开时可下载；**关闭页面后再进，上传与成品已清**
- [ ] iPhone Safari 至少能完成：进站 → 选两文件 → 生成 → 下载
- [ ] README：如何设置口令、如何启动、如何用假表自测
- [ ] 仓库无真实口令、无粤通卡真实生产数据
